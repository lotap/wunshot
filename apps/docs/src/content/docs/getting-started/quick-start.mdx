## Prerequisites

Before proceeding, make sure you have a typescript project and access to a postgresql database.

You will need the database connection URL available as an environment variable called `DB_URL`. (You can configure the expected name in `@/db/index.ts` and `drizzle.config.ts`)

## With Shadcn

:::caution
**Experimental**

Be aware that the shadcn cli is intended for use with frontend frameworks. It doesn't have a great way to handle when wunshot modules require changes to a core model. It is recommended to **always commit changes before adding a module and to investigate any overwrites to the core models carefully.**
:::

<Steps>

1.  Add the registry to your <a href="https://ui.shadcn.com/docs/components-json">`components.json`</a>

    ```json title="components.json"
      // ...
      "registries": {
        "@wunshot": "https://registry.wunshot.dev/{name}.json"
      }
    ```

2.  Use your preferred package manager with the <a href="https://ui.shadcn.com/docs/cli#add" target="_blank" rel="noopener noreferrer">shadcn cli</a>

    <Tabs syncKey="packageManager">

      <TabItem label="pnpm">

        ```sh
          pnpm dlx shadcn@latest add @wunshot/init
        ```

      </TabItem>

      <TabItem label="npm">

        ```sh
          npx shadcn@latest add @wunshot/init
        ```

      </TabItem>

      <TabItem label="yarn">

        ```sh
          yarn shadcn@latest add @wunshot/init
        ```

      </TabItem>

      <TabItem label="bun">

        ```sh
          bunx --bun shadcn@latest add @wunshot/init
        ```

      </TabItem>

    </Tabs>

    {/* This should automatically install dependencies and create a `db` folder in your project like this: */}

        {/* <FileTree>

    :::note
    You may need to update the driver based on your database provider. The `node-postgres` driver is used by default. You can configure the driver in `@/db/index.ts`
    :::

3.  Add scripts to your `package.json`
