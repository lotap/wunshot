## Contributing

If you encounter any bugs or have any feature requests, please [open an issue](https://github.com/lotap/wunshot/issues/new).

## Running locally

1. Clone the repo
2. `pnpm install`
3. `pnpm build:docs`
4. `cd ./apps/docs`
5. `pnpm preview`
